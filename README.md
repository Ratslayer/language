# Language Reader
The reader opens on **Books** with the translation language in the top-right corner. Tap a book to resume at your bookmark. Its source language comes from the book. To import a UTF-8 text file (up to 4 MiB) or a scanned or selectable-text PDF (up to 32 MiB), choose **Open local file…**. Tap a word while reading for its meaning and dictionary form in context. Tap **Translate sentence** to reveal the whole translation. Exceptionally long sentences use a shorter local excerpt.

AI Pages 0.2.3 or later provides the Android file picker, ChatGPT sign-in, storage, and the fast-text profile (gpt-6-luna with reasoning effort none). PDF text is extracted on the device and reflows into reader pages. Choose the reading language before importing a scan. Pages without embedded text use offline OCR in that language. Open a PDF from the reader or choose AI Pages under **Open with** in Android Files. Unlock password-protected files before importing them. On AI Pages 0.2.5 or later, tapping a word sends the lookup directly. Recent translations and the page bookmark are saved locally. Saved short texts appear on the bookshelf. For longer texts, reselect the same file to resume.

Run `npm ci && npm run build` and serve `dist/` over localhost for a browser preview. Plain-text import, pagination, and bookmarks work in the browser. PDF import and live translation require AI Pages.

AI Pages 0.2.6 adds local SQLite books. Use **Open book or language file** to pick a prepared book.sqlite in Android Files or Drive. Use the same button again to import the matching en.sqlite or another target language. The Android TXT/PDF picker also builds local books, including scanned pages through the existing OCR pipeline. Selecting a saved book restores its reading position.

**Offline files → Prepare this page** generates a fluent translation of each complete passage and a separate contextual gloss for each tappable source word with Luna. Function words and idiom components each get their own entry. Each complete sentence is validated and committed before requesting the next one. Pausing keeps that progress. Reopening after process termination resumes an unfinished page. A saved translation works without a connection. **Save language file…** exports a standalone SQLite snapshot via the Android picker. Save to a fresh filename when a snapshot already exists. Import merges finished sentences and retains local progress. The original prepared book can be exported separately.

AI Pages 0.2.7 opens the reader to a book grid. The page connects to its built-in Google Drive catalogue automatically on first open. Pull down at the top of Books to refresh. On AI Pages 0.3.0 or later, tapping a downloaded book opens the saved reading position immediately. The reader checks the catalogue in the background and applies updated pages and translations as they arrive. On first download, reading can start as soon as the source is installed. Choose a translation language on Books. The shelf shows coverage for that language and downloads its available pack when opening a book. On a fully translated page, open the pull-down panel and choose **Read in Russian** (or the selected language) to read the complete translated passage with its illustrations. Choose **Read original** to return to word lookups. The translated-page count includes fully prepared pages offered by Drive or already available on the device.

To publish an update, upload the finished SQLite files to Drive first, then replace the contents of the same catalogue file. The version-1 JSON object contains a `books` array. Each book has a stable `id` (a lowercase slug), `title`, optional `author`, the SQLite metadata’s `bookId`, the total number of reader `pages`, and a `source` object with a Drive `fileId` and lowercase hex `sha256`. Each entry in `languages` (for example `en`) has its own file ID, checksum, and `readyPages` array of zero-based page numbers. Include a page only when every sentence has a completed translation. The reader keeps a local copy of the catalogue for offline access.


AI Pages 0.3.0 gives Language a private directory. Language opens the source and translation databases with bundled SQLite, imports documents, validates downloads, merges translations, and manages the catalogue offline. The upgrade reuses existing SQLite files, catalogue checkpoints, and bookmarks.

Pull down past the top of a reading page to open its controls. With a mouse or trackpad, scroll up past the top. With a keyboard, press **Alt+Down**. The controls use the whole reading area. Enter a page number or scroll through the chapters and tap one to jump to its first sentence. Back returns to the same reading position. From the passage, Back returns to Books. Swipe left to advance one page and right to go back. Pages slide in the swipe direction. The controls slide down when opened and slide up on Back. An upward swipe at the end of the chapter list also closes them. The reader derives chapters from labels in the book, including repeated labels and chapters that start partway down a page. Unlabelled documents keep the page controls. On older AI Pages versions, the reader collects chapter labels when the panel first opens.

Prepared books can include inline illustrations. Add an optional SQLite table
`illustrations(sid INTEGER, position INTEGER, width INTEGER, height INTEGER, mime TEXT, alt TEXT, data BLOB, PRIMARY KEY(sid,position))`.
Tap an illustration to open it full screen. Pinch or double-tap to zoom, then drag to pan. The viewer also supports wheel zoom, keyboard controls and Android Back.

Each image appears before the sentence with the matching ID. Use the first caption sentence as its anchor. Images sharing an anchor are displayed in position order. Store JPEG, PNG, or WebP bytes and their pixel dimensions. Local and catalogue imports both keep these images offline on AI Pages 0.3.0 or later.

On AI Pages 0.3.0 or later, the reader saves one self-contained bookmark page per book. Reopening in the same translation language restores the passage, word meanings and illustrations from that small file. Source replacements and translation writes invalidate it. Existing installations populate it as pages are read.

Catalogue books can also offer an independent first page for new downloads. Build it with `python3 scripts/make-opening-page.py catalogue.json BOOK-SLUG book.sqlite opening.json ru=ru.sqlite`, adding any other available language files in the same form. Upload the result alongside the book with the same reader access. Add its Drive `fileId` to the printed checksum object and put that object in the book’s optional `openingPage` field. Publish the catalogue last. The reader displays that page, including its illustrations and available translations, while installing the complete book for offline use. A changed source checksum disables the old opening page. A changed language checksum omits the old meanings.
